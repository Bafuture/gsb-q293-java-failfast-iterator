## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的集合被并发修改时，迭代器会悄悄给出错误结果甚至死循环。请从零实现一个带并发修改检测的迭代器组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持快速失败模式：迭代期间集合被结构性修改时立即抛出并发修改异常，异常信息要指出期望版本与实际版本；2) 支持快照模式：迭代基于创建时的快照，后续修改不影响本次迭代且不抛异常；3) 两种模式由调用方选择，并说明各自适用场景；4) 支持弱一致模式：允许看到部分修改，但不得出现重复元素或死循环，需有测试证明；5) 支持并发压测：写线程持续修改的同时多线程迭代，三种模式的行为都要符合各自语义；6) 支持统计：迭代次数、检测到的并发修改次数与被放弃的迭代数；7) 说明三种模式的性能与一致性取舍，并给出耗时对比；8) 测试覆盖快速失败、快照隔离、弱一致不重复不死循环、并发压测与统计；`mvn -q verify` 一条命令跑通。
